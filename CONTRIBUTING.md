# Contributing

This repository is a [Homebrew tap](https://docs.brew.sh/Taps) — it only
publishes Homebrew formulas (`.rb` files). It is not a general-purpose source
repository.

## What belongs here

- `Formula/<name>.rb` — a formula per installable CLI, generated from the
  published npm package by `scripts/generate-brew-formula.ts`.
- `scripts/` — generator tooling (Node + TypeScript, run with `tsx`).
- `.github/workflows/` — CI validation and the post-release regenerate job.

## Adding a new CLI

1. Add a formula under `Formula/` (copy `podyard.rb` as a starting point and
   adapt the metadata).
2. If the formula is generated from an npm package, extend
   `scripts/generate-brew-formula.ts` (or add a sibling script) so the release
   workflow can regenerate it.
3. Add a CI check for the new formula (see `.github/workflows/ci.yml`).
4. Open a pull request.

## Updating an existing formula

Formulas are **generated**, not hand-edited. To bump `podyard`:

```bash
pnpm install
pnpm run generate            # latest published version
pnpm run generate 0.2.0      # or a specific version
git add Formula/podyard.rb
git commit -m "release: stamp @podyard/cli@0.2.0 into the Homebrew formula"
git push
```

In normal operation you do not need to do this manually — the
[Regenerate formula](.github/workflows/regenerate.yml) workflow runs after each
CLI release and commits the updated formula to `main` automatically.

## Verifying locally

```bash
brew style Formula/podyard.rb        # style check
brew audit Formula/podyard.rb        # audit (warnings may be acceptable)
brew install --build-from-source podyard/homebrew-tap/podyard   # full build test
podyard --version
```

## Conventions

- Node 22 (see `.nvmrc`) and pnpm for tooling in this repo.
- Two-space indentation everywhere (see `.editorconfig`).
- Keep the "Generated by … do not edit by hand" header on generated files.
